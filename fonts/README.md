# Fonts for Settings > Look and text size > Font (3.157.0)

Latin subsets of variable fonts (width + weight axes) from Google Fonts, used by `src/styles/107-fonts.css`.
All are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org):

- `mona-sans.woff2`: Mona Sans, Copyright 2023 The Mona Sans Project Authors (github.com/github/mona-sans)
- `roboto-flex.woff2`: Roboto Flex, Copyright 2017 The Roboto Flex Project Authors (github.com/googlefonts/roboto-flex)
- `saira.woff2`: Saira, Copyright 2016 The Saira Project Authors (github.com/Omnibus-Type/Saira)
- `noto-sans.woff2`: Noto Sans, Copyright 2022 The Noto Project Authors (github.com/notofonts/latin-greek-cyrillic)
- `roboto-serif.woff2`: Roboto Serif, Copyright 2020 The Roboto Serif Project Authors (github.com/googlefonts/roboto-serif)

Archivo, the default, is embedded in the page (`src/styles/010-fonts.css`).
A new choice must have a width (wdth) axis: Slate's condensed scores and wide titles depend on it.
