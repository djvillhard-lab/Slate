# Page handoff notes

One short file per page or area (`slate.md`, `live-feed.md`, `best-bets.md`, `all-games.md`, `game.md`, `teams.md`,
`box-office.md`, `news.md`, `tv.md`, `notifications.md`, `settings.md`, `ios.md`), named after the areas in CLAUDE.md.

Each thread that works on a page updates its note in the same push as the change. Keep it under about 30 lines:

```
# <Page>
Last updated: <date>, <version>

## Done
- what works now, in a line each

## Open
- what's next or half-done, and what DJ asked for that isn't built yet

## Decisions
- choices DJ made or that were tried and undone, and why (so nobody tries them again)
```
